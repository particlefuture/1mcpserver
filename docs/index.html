1 MCP Server

Find, configure, and run MCP servers in one click.

ONCE AND FOR ALL.

Get Started

Cursor

For Cursor: Add the following code to .cursor/mcp.json in your cursor project directory.

{
  "mcpServers": {
    "mcp-server-discovery": {
      "url": "https://mcp.1mcpserver.com/mcp/",
      "headers": {
        "Accept": "text/event-stream",
        "Cache-Control": "no-cache"
      }
    }
  }
}

Claude

For Claude: Open the following file based on your operating system:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\\Claude\\claude_desktop_config.json

Add the following code to the file: Note you HAVE TO CLONE REPO

{
  "mcpServers": {
    "1mcpserver": {
      "command": "/path/to/uv",
      "args": [
        "--directory",
        "PATH_TO_CLONED_REPO",
        "run",
        "server.py",
        "--local"
      ]
    }
  }
}

Gemini CLI

For Gemini CLI: Add the following code to .gemini/settings.json in your project directory.

{
  "mcpServers": {
    "mcp-server-discovery": {
      "url": "https://mcp.1mcpserver.com/mcp/",
      "headers": {
        "Accept": "text/event-stream",
        "Cache-Control": "no-cache"
      }
    }
  }
}

Codex

For Codex: Add the following code to ~/.codex/config.toml (macOS) or %USERPROFILE%\.codex\config.toml (Windows).

[mcpServers.mcp-server-discovery]
url = "https://mcp.1mcpserver.com/mcp/"

[mcpServers.mcp-server-discovery.headers]
Accept = "text/event-stream"
Cache-Control = "no-cache"
